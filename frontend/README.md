# NPC Management — Frontend

React 19 + TypeScript SPA built with Vite 8 and managed with yarn. See the [root README](../README.md) for the full-stack picture; this covers the frontend half.

## Stack

- **TanStack Router** — file-based, type-safe routing (`src/routes/`)
- **Tailwind CSS v4** — configured via the Vite plugin, no `tailwind.config` file
- **shadcn/ui** — radix base, Nova preset, Geist font; components copied into `src/components/ui/`
- **ESLint (flat config) + Prettier** — typescript-eslint, react-hooks, react-refresh

## Commands

```sh
yarn              # install dependencies
yarn dev          # dev server on http://localhost:5173
yarn build        # type-check (tsc -b) + production build to dist/
yarn preview      # serve the production build
yarn lint         # ESLint
yarn format       # Prettier — write
yarn format:check # Prettier — check only (CI-friendly)
```

`yarn dev` proxies `/api/*` to the backend at `http://localhost:5000` (see `vite.config.ts`), so call the API with relative URLs: `fetch('/api/npcs')`. Start the backend first — from `../backend`, run `dotnet run --project NpcManagement.Api --launch-profile http`.

## Source layout

```
src/
  routes/            # one file per route
    __root.tsx       #   shared layout: nav header + <Outlet />
    index.tsx        #   "/" home page
  routeTree.gen.ts   # generated by the router plugin — never edit, ignored by lint
  components/ui/     # shadcn/ui components (yours to edit)
  lib/utils.ts       # cn() helper for merging Tailwind classes
  index.css          # Tailwind import + shadcn theme variables
```

The `@` import alias points at `src/` (configured in `vite.config.ts` and both tsconfigs):

```tsx
import { Button } from '@/components/ui/button'
import { cn } from '@/lib/utils'
```

## Routing

Add a file under `src/routes/` and the route appears while `yarn dev` runs (the plugin regenerates `routeTree.gen.ts`):

```tsx
// src/routes/npcs.tsx  →  /npcs
import { createFileRoute } from '@tanstack/react-router'

export const Route = createFileRoute('/npcs')({
  component: NpcsPage,
})

function NpcsPage() {
  return <div>NPC list goes here</div>
}
```

- Path params: `npcs.$npcId.tsx` → `/npcs/:npcId`, read with `Route.useParams()`
- Layout for everything: `__root.tsx`
- `<Link to="...">` is type-checked against the route tree — broken links fail `yarn build`

If `routeTree.gen.ts` is missing or stale (e.g. fresh clone, route renamed outside dev), running `yarn dev` or `npx vite build` regenerates it.

## shadcn/ui

```sh
npx shadcn@latest add dialog        # one component
npx shadcn@latest add table badge   # several at once
```

Components are copied as source into `src/components/ui/` — edit them freely, there's no package to stay in sync with. Catalogue: https://ui.shadcn.com/docs/components

Theming lives in `src/index.css` as CSS variables: `:root` for light, `.dark` for dark (enable dark mode by adding the `dark` class to `<html>`). Use the semantic Tailwind classes (`bg-background`, `text-muted-foreground`, `border-border`, …) rather than raw colours so both themes work.

## Linting notes

Two deliberate exceptions in `eslint.config.js` — don't "fix" code to satisfy them:

- `react-refresh/only-export-components` is **off** in `src/components/ui/**` (shadcn exports helpers like `buttonVariants` beside components) and `src/routes/**` (the router plugin handles HMR for route files itself).
- `src/routeTree.gen.ts` is ignored by ESLint and Prettier (generated file).
